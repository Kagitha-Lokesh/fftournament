# STEP 5 — VISUAL ASSET DIRECTION

The landing page needs its own visual identity.

The mistake would be to take Free Fire promotional artwork and simply put website text around it.

Instead:

> **Build a tournament-platform visual world that uses Free Fire as the competitive context.**

That distinction is what will make the site feel like a real product.

# 4. YELLOW IS A SIGNAL

This is an important rule.

Yellow should mean:

> **Pay attention.**

Therefore use it for:

* active state
* verified indicator

Don't use yellow for:

* entire backgrounds

* large text blocks
* every heading
* every icon

If everything is yellow, nothing is important.
